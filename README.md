# Book Recommendation Diary

## Project Description

Book Recommendation Diary is an Android mobile application designed to help users record, manage, and review books they have read. The app allows users to create a personal diary of book recommendations, rate books, and add short reviews. This helps users keep track of their reading history and easily revisit their favorite books.

The application includes a user authentication system and uses a local SQLite database to store user and book data.

---

## Features

* User Registration and Login
* Add New Books
* Edit Book Details
* Delete Books
* Rate Books
* Write Short Reviews
* View Books in a RecyclerView List
* Local Data Storage using SQLite

---

## Technologies Used

Programming Language: Java
Platform: Android
IDE: Android Studio
Database: SQLite
UI Components: RecyclerView, EditText, Button, TextView
